# Redesign R3: Link previews

Date: 2026-10-03 (started 2026-10-02). Plan: `layout_redesign.md`, Slice R3. Status: implemented and independently reviewed; three earlier Polish audit methods remain failing.

## Implementation

- `LinkPreviewExtractor` (ChatCore) detects at most three distinct HTTP(S) URLs from finished assistant text, retaining encounter order. Gateway-origin URLs, known Gateway media/artifact paths, explicit media references, credentials, non-web schemes, common code examples, and inline/reference Markdown image destinations are excluded. Host casing, default ports, and fragments are normalized for deduplication; the first original URL remains the navigation/copy/share destination.
- `LinkPreviewLoader` (app) wraps Apple's `LPMetadataProvider`, including optional image/icon data. The public metadata API provides a title and URLs, so the displayed site name is the original URL's domain. No third-party dependency or persistence change.
- Testable ChatCore seams own request deadlines, cancellation, completed-only `NSCache`, and presentation generations. Native metadata plus subresource decoding has an eight-second overall deadline; compressed inputs larger than 5 MiB are discarded, and ImageIO downsamples preview rasters to at most 1024 pixels per side (icons: 128). Failed/timed-out requests show a domain card and remain retryable. Cancelling one card cannot cancel another card: only completed results are shared, while each active request owns its provider.
- Cards use theme colors, interactive glass with an opaque theme base for contrast, and a flat surface with Reduce Transparency. Text has Dynamic Type styles; accessibility sizes stack the artwork above text. VoiceOver sees one link element. Tap opens `SFSafariViewController`; the context menu offers Copy Link and Share.
- Settings owns `showLinkPreviews`, default on. When off, preview views and tasks are absent and the inline Markdown remains unchanged. View disappearance invalidates presentation state, and task cancellation cancels metadata/image providers; late callbacks cannot cache or publish cancelled results.
- `-DemoLinkPreviews` seeds final, offline-fallback, and streaming URLs through FakeGateway. Its stub generates local raster artwork and a favicon so screenshots exercise both image surfaces. All `-Demo*`, `-FakeGateway`, and onboarding-preview launches select the deterministic metadata stub, including future Demo modes. Tests never contact a real Gateway or external metadata site.

## Choices and limits

- URL extraction uses `NSDataDetector` plus conservative lexical exclusions for common Markdown code/images; Textual still owns rendering/parsing. This is not a complete Markdown parser. Reference definitions used by an image are excluded even if that definition is also shared by an ordinary text link.
- Metadata/icon/image data lives only in the bounded in-memory preview cache (40 entries, 24 MiB byte-cost limit), and never in SwiftData or the transcript cache. Native `NSItemProvider` loads are individually cancelled when their request ends.
- Concurrent first-time requests for the same URL are independent rather than coalesced. This keeps provider cancellation local to the requesting card; subsequent requests reuse completed metadata.
- The deterministic UI test exercises card contents, Copy/Share availability, the Settings gate, and four preview and four Settings screenshot variants. Safari presentation is implemented but not opened by the test, because a browser navigation could contact the third-party site.
